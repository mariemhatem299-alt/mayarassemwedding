# Mayar & Assem — Wedding Gift Website

A ready-to-upload static website for GitHub Pages.

## Upload
1. Create a new GitHub repository.
2. Upload **all contents of this folder** (keep the `assets` folder).
3. In GitHub: Settings → Pages → Deploy from branch → choose `main` and `/root`.
4. Open the generated GitHub Pages link.

The site is responsive and works on mobile.
